QuickSend Privacy Policy

Last updated: November 14, 2026 (2026-11-14). Developer: Osvald Studio. Privacy contact: osvald.studio26@gmail.com.

QuickSend lets you save a message and send it to a Telegram chat with a tap. This policy covers the Android and iPhone apps. QuickSend is an unofficial client using the Telegram API and TDLib; it is not affiliated with, endorsed by, or operated by Telegram. Українською

Information used and stored on your device

  • Android: your Telegram API ID and API hash are saved in an encrypted file in QuickSend’s private, non-backed-up storage. The encryption key is protected by Android Keystore. TDLib keeps the Telegram session and cached account, chat, contact, message and file data in the app’s private files folder. Its database is encrypted with a key protected by Android Keystore.
  • iPhone: your Telegram API ID and API hash are saved in the iOS Keychain. TDLib keeps the Telegram session and cached data in QuickSend’s private Application Support folder, separately from the widget. The TDLib database is encrypted; its key is also in the Keychain. These Keychain items are set to stay on this device without iCloud Keychain sync. The TDLib folders are excluded from backup.
  • Saved messages and results: QuickSend saves template text and labels, recipient details (including chat previews and profile-photo file paths), Telegram account identifiers and send results on the device. Android uses private app storage, including DataStore and widget settings. On iPhone, templates and last send results are JSON files in an App Group container shared by QuickSend and its widget; the widget reads them to display your messages and their status. A send journal is also kept in the app’s private Application Support folder.
  • QuickSend saves appearance preferences locally. Android also saves the account phone number for Settings; on iPhone, Settings uses the phone number supplied by the current Telegram session.
  • Your phone number, login code and, if required, two-step verification password are used to sign in to Telegram. QuickSend does not save the login code or password in its templates or preferences.

Purpose, transmission and sharing

When you sign in, QuickSend sends your phone number, login code and any required two-step verification password to Telegram through TDLib. TDLib also sends the API credentials, language, device model, operating-system version and app version needed for the connection. QuickSend reads your Telegram chats and Telegram contacts so you can choose a recipient and see chat previews and profile photos. It does not request access to your phone’s address book.

When you tap to send a saved message, QuickSend sends its text and recipient’s chat identifier to Telegram through TDLib. On iPhone, tapping a send widget opens QuickSend to send the message and show the result. Telegram processes the data it receives under its own Privacy Policy.

QuickSend has no server or account system of its own, no analytics, no ads and no tracking. The app does not send your API credentials, session, phone number, contacts, messages or templates to the developer.

Opening this policy in your browser contacts GitHub Pages, which hosts it and may process standard web request information such as your IP address. If you email the developer, your email address and message are used to reply. Do not send API keys, login codes or passwords.

Retention, security and deletion

You can delete individual templates in the app. Log out in Settings to end the Telegram session. Logging out does not erase saved templates, results, appearance preferences or API credentials. Templates remain tied to the Telegram account they were saved for.

Android: to remove all local QuickSend data, clear the app’s storage in Android Settings or uninstall it. App backup and device-transfer exclusions are configured for private app files.

iPhone: log out before deleting QuickSend. Use Delete App, rather than Offload App, to remove its local app and widget files and preferences. Keychain items can remain after deletion, including API credentials and the database key. The current app has no user-facing control to erase all Keychain items, so deleting the app is not a guarantee that every local credential is erased.

Logging out or deleting QuickSend does not delete your Telegram account or messages already sent to Telegram. Manage messages, active sessions and account deletion in Telegram. A send already accepted by Telegram may still finish; check the chat before sending the same text again.

API credentials and TDLib databases have the protections described above. Template text, last results and send journals do not have separate QuickSend encryption. Keep your device and screen lock secure.

Your choices and changes to this policy

You can stop using QuickSend, log out or remove local data as described above. QuickSend is not directed at children; use of Telegram is subject to Telegram’s eligibility rules. Changes to this policy will appear here with an updated date. For privacy questions, use the contact address above.

Політика конфіденційності QuickSend

Останнє оновлення: 14 листопада 2026 року (2026-11-14). Розробник: Osvald Studio. Контакт із питань конфіденційності: osvald.studio26@gmail.com.

QuickSend дає змогу зберегти повідомлення й надіслати його в чат Telegram одним натисканням. Ця політика охоплює застосунки для Android та iPhone. QuickSend — неофіційний клієнт, що використовує Telegram API і TDLib; він не пов’язаний із Telegram, не керується ним і не має його схвалення.

Які дані зберігаються на пристрої

  • Android: ваші Telegram API ID та API hash зберігаються в зашифрованому файлі у приватному сховищі QuickSend, що не потрапляє до резервних копій. Ключ шифрування захищено Android Keystore. TDLib зберігає сеанс Telegram та кешовані дані акаунту, чатів, контактів, повідомлень і файлів у приватній папці файлів застосунку. База даних зашифрована ключем, захищеним Android Keystore.
  • iPhone: ваші Telegram API ID та API hash зберігаються у В’язці ключів iOS (Keychain). TDLib зберігає сеанс Telegram і кешовані дані у приватній папці Application Support застосунку QuickSend, окремо від віджета. База даних TDLib зашифрована; її ключ також зберігається у Keychain. Для цих записів Keychain налаштовано зберігання лише на цьому пристрої без синхронізації через iCloud Keychain. Папки TDLib виключено з резервного копіювання.
  • Шаблони та результати: QuickSend зберігає на пристрої текст і назви шаблонів, дані одержувачів (зокрема попередній перегляд чатів і шляхи до файлів фото профілів), ідентифікатори акаунтів Telegram та результати надсилання. На Android використовується приватне сховище застосунку, зокрема DataStore і налаштування віджетів. На iPhone шаблони й останні результати надсилання зберігаються у JSON-файлах у спільному контейнері App Group застосунку QuickSend та його віджета; віджет читає їх для показу повідомлень і стану надсилання. Журнал надсилання також зберігається у приватній папці Application Support застосунку.
  • QuickSend локально зберігає налаштування вигляду. Android також зберігає номер телефону акаунту для показу в налаштуваннях; на iPhone використовується номер, отриманий із поточного сеансу Telegram.
  • Номер телефону, код входу та, за потреби, пароль двоетапної перевірки використовуються для входу в Telegram. QuickSend не зберігає код входу чи пароль у шаблонах або налаштуваннях.

Використання та передавання

Під час входу QuickSend передає ваш номер телефону, код входу та, за потреби, пароль двоетапної перевірки до Telegram через TDLib. TDLib також передає потрібні для з’єднання дані API, мову, модель пристрою, версію операційної системи й застосунку. QuickSend читає ваші чати й контакти Telegram для вибору одержувача та показу попереднього перегляду чатів і фото профілів. Доступ до адресної книги телефону не запитується.

Коли ви натискаєте для надсилання збереженого повідомлення, QuickSend передає його текст та ідентифікатор чату одержувача до Telegram через TDLib. На iPhone натискання віджета надсилання відкриває QuickSend, щоб надіслати повідомлення й показати результат. Telegram обробляє отримані дані згідно зі своєю політикою конфіденційності.

QuickSend не має власного сервера чи системи акаунтів, аналітики, реклами або відстеження. Застосунок не передає розробнику ваші ключі API, сеанс, номер телефону, контакти, повідомлення чи шаблони.

Відкриття цієї політики в браузері створює запит до GitHub Pages, де розміщено сторінку; хостинг може обробляти стандартні дані вебзапиту, зокрема IP-адресу. Якщо ви пишете розробнику, ваша електронна адреса й лист використовуються для відповіді. Не надсилайте ключі API, коди входу чи паролі.

Строк зберігання, безпека та видалення

Окремі шаблони можна видалити в застосунку. Вийдіть з акаунту в налаштуваннях, щоб завершити сеанс Telegram. Вихід не видаляє збережені шаблони, результати, налаштування вигляду чи ключі API. Шаблони залишаються прив’язаними до акаунту Telegram, для якого їх збережено.

Android: щоб видалити всі локальні дані QuickSend, очистьте сховище застосунку в налаштуваннях Android або видаліть його. Для приватних файлів налаштовано виключення з резервного копіювання та перенесення на інший пристрій.

iPhone: вийдіть з акаунту перед видаленням QuickSend. Виберіть «Видалити застосунок», а не «Згрузити застосунок», щоб прибрати локальні файли застосунку й віджета та налаштування. Записи Keychain можуть залишитися після видалення, зокрема ключі API та ключ бази даних. Поточна версія не має доступної користувачу функції очищення всіх записів Keychain, тому видалення застосунку не гарантує видалення всіх локальних облікових даних.

Вихід або видалення QuickSend не видаляє ваш акаунт Telegram чи повідомлення, уже надіслані до Telegram. Керуйте повідомленнями, активними сеансами й видаленням акаунту в Telegram. Надсилання, уже прийняте Telegram, може завершитися пізніше; перевірте чат перед повторним надсиланням.

Ключі API та бази даних TDLib захищено описаними вище засобами. Текст шаблонів, останні результати й журнали надсилання не мають окремого шифрування QuickSend. Захищайте пристрій і блокування екрана.

QuickSend не призначено для дітей; діють правила Telegram щодо права користування сервісом. Зміни політики з’являтимуться тут з оновленою датою.
