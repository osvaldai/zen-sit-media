QuickSend Privacy Policy

Effective date: November 2, 2026. Developer: Osvald Studio. Privacy contact: osvald.studio26@gmail.com.

QuickSend is an unofficial app using the Telegram API and TDLib. It is not affiliated with, endorsed by, or operated by Telegram. This policy covers the Android app. Українською

Information used and stored on your device

  • Your Telegram API ID and API hash are stored encrypted using Android Keystore. They are used to connect your own Telegram API client.
  • TDLib stores your Telegram session, account and phone information, chat and contact metadata, message history or previews, profile photos and cached files in the app’s private storage. This session allows QuickSend to remain logged in.
  • QuickSend stores message presets, their text and labels, recipient and account identifiers, chat previews, widget bindings and send status locally. It also stores appearance preferences and may store your account phone number to display in Settings.
  • Your phone number, login code and optional two-step verification password are used to sign in with Telegram. QuickSend does not intentionally save the login code or password in saved instance state or preferences. They are held in memory during authentication.

Purpose, transmission and sharing

QuickSend reads your Telegram chats and Telegram contacts to let you choose a recipient, shows previews and profile photos, and sends the text you choose when you tap a send widget. Access to Telegram contacts does not require access to your device’s address book; QuickSend does not request that permission.

Account authentication, API credentials and message/recipient data needed for these functions go only to Telegram servers through TDLib. Telegram processes this information under its own Privacy Policy. QuickSend does not send your information to the developer, operate a developer data server, or include advertising or analytics services. The developer does not receive your API credentials, session, phone number, contacts, messages or presets.

Opening the privacy-policy link uses your browser and contacts the policy host, GitHub Pages. That host may process standard web request information such as your IP address under its own policy. If you email the developer, the email service processes your message and address so the developer can reply; do not send login credentials or codes.

Retention, security and deletion

Local data is retained while the app is installed, until you delete it. Delete individual presets in the app. Logging out ends the local Telegram session; presets and preferences may remain for your convenience and are bound to their original Telegram account. Replacing API keys resets the local TDLib session. To delete all local credentials, presets, session files and preferences, clear QuickSend’s app storage in Android Settings or uninstall it. App backup and device-transfer exclusions are configured for private app files.

Logging out or uninstalling QuickSend does not delete your Telegram account or messages already delivered to Telegram. Manage those messages, active sessions and account deletion in Telegram. Pending sends may still be processed by Telegram; check the chat before sending the same text again.

Private app storage and Keystore encryption protect local API keys, but no device or transmission method provides an absolute security guarantee. TDLib session files and preset text are in private app storage; they do not have separate QuickSend encryption. Keep your device and screen lock secure.

Your choices and changes to this policy

You can stop using QuickSend at any time, log out or delete its local data as described above. The app is not directed at children; use of Telegram is subject to Telegram’s eligibility rules. Material changes to this policy will be reflected on this page with an updated effective date. Contact the developer at the address above for privacy questions.

Які дані зберігаються на пристрої

API ID та API hash зберігаються зашифрованими за допомогою Android Keystore. TDLib зберігає сеанс Telegram, дані акаунту й номера телефону, контакти Telegram, відомості про чати, історію або попередній перегляд повідомлень, фото профілів та кешовані файли у приватному сховищі застосунку. QuickSend локально зберігає текст і назви шаблонів, ідентифікатори одержувача та власника акаунту, прив’язки віджетів, стан надсилання й налаштування вигляду. Номер телефону може зберігатися для показу в налаштуваннях.

Номер телефону, код входу та пароль двоетапної перевірки використовуються для авторизації в Telegram. QuickSend не записує код або пароль до збереженого стану екрана чи налаштувань; під час входу вони перебувають лише в пам’яті.

Використання та передавання

Доступ до чатів і контактів Telegram потрібний для вибору одержувача, показу попереднього перегляду й надсилання вибраного тексту після натискання віджета. QuickSend не запитує доступ до адресної книги пристрою. Необхідні дані авторизації, API та повідомлень передаються через TDLib лише серверам Telegram, який обробляє їх згідно зі своєю політикою конфіденційності. Розробник не отримує ваші ключі API, сеанс, номер телефону, контакти, повідомлення або шаблони. У застосунку немає реклами чи аналітики.

Посилання на цю політику відкриває браузер і сайт GitHub Pages; хостинг може обробляти стандартні дані вебзапиту, зокрема IP-адресу, за власною політикою. Якщо ви пишете розробнику електронною поштою, поштова служба обробляє вашу адресу та лист для відповіді. Не надсилайте коди входу чи паролі.

Строк зберігання, безпека та видалення

Локальні дані залишаються на пристрої до їх видалення. Окремий шаблон можна видалити в застосунку. Вихід з акаунту завершує локальний сеанс Telegram; шаблони й налаштування можуть залишитися та прив’язані до початкового акаунту. Заміна ключів API скидає локальний сеанс TDLib. Щоб видалити всі локальні ключі, сеанс, шаблони та налаштування, очистьте сховище QuickSend у налаштуваннях Android або видаліть застосунок. Для приватних файлів налаштовано виключення з резервного копіювання та перенесення.

Вихід або видалення застосунку не видаляє акаунт Telegram чи вже доставлені повідомлення. Керуйте повідомленнями, активними сеансами та видаленням акаунту в Telegram. Надсилання в очікуванні може завершитися пізніше; перевірте чат перед повторним надсиланням.

Ключі API захищено Android Keystore. Файли сеансу та текст шаблонів перебувають у приватному сховищі без окремого шифрування QuickSend. Абсолютної гарантії безпеки немає; захищайте пристрій і блокування екрана.

Ваш вибір і зміни політики

Ви можете припинити використання, вийти з акаунту або видалити локальні дані. Застосунок не призначено для дітей; діють вікові правила Telegram. Зміни політики буде оприлюднено тут з оновленою датою. Запитання надсилайте на контактну адресу вище.
